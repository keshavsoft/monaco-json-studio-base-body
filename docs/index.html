monaco-json-studio-base-body

Handlebars (.hbs) 1-, 2-, and 3-pane body layouts with Monaco runtime helpers.

npm Package GitHub Repo Suite Story & Docs Base Header Base Footer

The Story

Keeping single.hbs, double.hbs, and triple.hbs inside a dedicated body repo lets any HTML shell switch between 1, 2, or 3 panes while keeping headers and footers independent.

CLI & API

npx monaco-json-studio-base-body double
npx monaco-json-studio-base-body triple --html
