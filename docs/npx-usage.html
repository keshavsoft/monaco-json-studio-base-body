CLI (npx) Usage

Run monaco-json-studio-base-body directly from the terminal without cloning.

Commands

npx monaco-json-studio-base-body single
npx monaco-json-studio-base-body double
npx monaco-json-studio-base-body triple --html

Generates a standalone preview folder (./body-<layout>, auto-incrementing -1, -2 if it exists) or prints the compiled .hbs markup with --html.
